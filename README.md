# Automated-Conveyor-Sorting-System
Overview

Designed and prototyped an automated conveyor sorting system using Arduino, Python, computer vision, and 3D-printed components. The system identifies objects or colors through a camera feed and actuates a servo-based sorting mechanism to direct items into designated bins.

Technologies Used
Arduino Uno
Python
OpenCV
SolidWorks
Servo Motors
DC Motor
L298N Motor Driver
3D Printing
Features
Real-time camera detection
Automated object sorting
Arduino-Python communication
CAD-designed conveyor assembly
Prototype manufacturing and testing
Future Improvements
Multi-bin sorting
Improved conveyor drive system
